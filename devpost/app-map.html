2. Code Tour Route (Key Locations)

  • Stop 1: Reactive State Store — src/hooks/useGateMasterStore.ts
    Manages the 2x2 matrix values, Boolean inputs, and triggers celebratory confetti when mathematical conditions (determinant = 0 or carry generated) are met.
  • Stop 2A: Linear Algebra Renderer — src/components/linear-algebra/VectorCanvas.tsx
    Executes native 2D affine matrix transformations on coordinate points, draws glowing basis vectors î and ĵ, and paints the shaded determinant parallelogram.
  • Stop 2B: Digital Logic Circuit Renderer — src/components/digital-logic/CircuitCanvas.tsx
    Draws the Half-Adder schematic (XOR & AND gates) with animated electric wire glow and dynamic Sum/Carry LED status rings.
  • Stop 3: Resilient Persistence Hook — src/hooks/usePersistence.ts
    Generates anonymous session UUIDs, writes immediately to browser localStorage, and executes background cloud sync to Supabase without blocking the UI.

3. "To Change This, Start Here"

Add a new Matrix Preset (e.g., Reflection or 45° Rotation)

Open src/components/linear-algebra/LinearAlgebraControls.tsx and add a new button inside the presets-group calling loadMatrixPreset({ a, b, c, d }).

Add a Full-Adder Circuit or OR Gate

Open src/components/digital-logic/CircuitCanvas.tsx. Extend the wire geometry and gate drawing helpers (like drawXORGate and drawANDGate) to accept a third Carry-In input.

Connect to your Live Supabase Project

Create a .env file in the project root with VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY. The client in src/lib/supabase.ts will automatically detect it.

4. A Practice to Reuse

Separating High-Frequency Rendering from State Persistence: When building interactive visualizers, never tie network requests or heavy React re-renders directly to drag/pointer events. Maintain high-frequency updates in local frame-rate loops, and restrict cloud sync to discrete, meaningful state milestones (like challenge victories or level completions).
